# Synthetic documentation figures

The three committed PNGs illustrate schemas using synthetic in-memory tables.
They contain no recording frames and make no accuracy claim.

| Figure | Demonstrates |
|---|---|
| `speaker_turn_strip.png` | Speaker turns and word timings |
| `active_speaker_strip.png` | Measured, carried and missing face activity |
| `pose_skeleton_strip.png` | BODY_25 keypoints and missing detections |

Back to [Datasets](../datasets.md), [Modalities](../modalities.md) or the
[overview](../../README.md).

## Brand assets

SVG under `brand/`, used by the landing page and generated by
[`scripts/make_brand_assets.py`](../../scripts/make_brand_assets.py) — edit the script, not the
SVG, and regenerate both variants together. No external fonts, images or scripts. Each light
variant sits on a white plate, each dark variant on GitHub's dark background (`#0d1117`); the
geometry is shared, only the palette differs. GitHub shows them as images, so their text is
not selectable: the README alt text carries the content.

| Asset | Purpose |
|---|---|
| `brand/logo.svg` | Square mark: waveform, pose figure and text lines drop onto one time axis |
| `brand/banner-{light,dark}.svg` | README header: mark, name, tagline and modality chips over a faint tier score |
| `brand/modalities-{light,dark}.svg` | Six lanes on one clock, a marker read across all of them, feeding one dataset directory |
| `brand/flow-{light,dark}.svg` | Five steps from one video to one dataset |

Every brand picture is synthetic: invented values, no recording, and the timeline says so
inside the picture. Lane names, tools and table paths follow
[Datasets](../datasets.md#table-reference) and
[`ARTIFACT_LAYOUT`](../../src/multimodal_pipeline/artifacts.py).

```bash
python3 scripts/make_brand_assets.py docs/assets/brand
```

## Regenerate

Run from the repository root:

```bash
uv run --with matplotlib python scripts/make_dataset_figures.py \
  --synthetic --seed 7 --out /tmp/storytel-doc-figures
cp /tmp/storytel-doc-figures/{speaker_turn_strip,active_speaker_strip,pose_skeleton_strip}.png docs/assets/
```

The generator also emits a stage graph; it is not committed or displayed. The
[dependency table](../architecture.md#stage-dependencies) is checked against the DAG.
Figure tests compare the three committed illustrations with regenerated bytes.
Matplotlib is optional, not a root dependency; those checks can skip without it.

Real-dataset figures are for local inspection only. Verify media rights before
redistributing any image derived from an input recording.
