# Synthetic documentation figures

The three committed PNGs illustrate schemas using synthetic in-memory tables.
They contain no recording frames and make no accuracy claim.

| Figure | Demonstrates |
|---|---|
| `speaker_turn_strip.png` | Speaker turns and word timings |
| `active_speaker_strip.png` | Measured, carried and missing face activity |
| `pose_skeleton_strip.png` | BODY_25 keypoints and missing detections |

Back to [Datasets](../datasets.md) or the [overview](../../README.md).

## Regenerate

Run from the repository root:

```bash
uv run --with matplotlib python scripts/make_dataset_figures.py \
  --synthetic --seed 7 --out /tmp/storytel-doc-figures
cp /tmp/storytel-doc-figures/{speaker_turn_strip,active_speaker_strip,pose_skeleton_strip}.png docs/assets/
```

The generator also emits a stage graph; it is not committed or displayed. The
[dependency table](../architecture.md#stage-dependencies) is checked against the DAG.
Figure tests compare the three committed illustrations with regenerated bytes.
Matplotlib is optional, not a root dependency; those checks can skip without it.

Real-dataset figures are for local inspection only. Verify media rights before
redistributing any image derived from an input recording.
