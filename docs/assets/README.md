# `docs/assets/` — committed figures, all synthetic

Every PNG here is generated by `scripts/make_dataset_figures.py --synthetic` from an
in-memory dataset with the same column shapes as the real Parquet tables. **None of them
contains a frame of processed video.** The pipeline runs on copyrighted broadcast
material (Telediario, Kimmel, CNN), so a derived image is not ours to redistribute, and
this repository is public. A synthetic strip demonstrates the *schema* — which columns
exist, how dense the frames table is, what a turn lane looks like against word timings —
which is what documentation needs from a picture anyway.

| Figure | Rendered from | What to read in it |
|---|---|---|
| `stage_graph.png` | `STAGE_ORDER` + `STAGE_DEPENDENCIES` | the real DAG; dashed boxes have their own enable check, so they can skip |
| `active_speaker_strip.png` | `speaker/active_speaker_frames.parquet` | one tick per frame coloured by `frame_reason`, the `talknet_score` trace, the `is_active_speaker` band |
| `speaker_turn_strip.png` | `speech/speaker_turns.parquet` + `speech/words.parquet` | turn lanes per `speaker_id` against word ticks on the same seconds |
| `pose_skeleton_strip.png` | `pose/body.parquet` | BODY_25 stick figures for sampled frames; a frame with nothing above the confidence floor says so in its own panel |

## Regenerate

```bash
uv run --with matplotlib python scripts/make_dataset_figures.py \
    --synthetic --seed 7 --out docs/assets
```

Matplotlib is deliberately not a project dependency — `uv run --with matplotlib` supplies
it per invocation. The output is deterministic: same seed, same column shapes, byte-identical
PNGs, so a commit that changes one of these files changed something real.
`tests/unit/test_make_dataset_figures.py` asserts that the committed bytes are exactly what
this command produces; if you edit the figures, rerun it and commit the result together.

To draw the same four figures from a real dataset — for your own inspection, never for
committing — pass `--dataset` instead:

```bash
uv run --with matplotlib python scripts/make_dataset_figures.py \
    --dataset data/processed/<video_id> --out /tmp/figs
```
